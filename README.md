## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Route Builder** | Map trade routes between sectors with ware and profit tracking |
| **Profit Estimator** | Estimate credits-per-hour for planned trade routes |
| **Fleet Planner** | Assign trade ships to routes with capacity and speed matching |
| **Ware Browser** | Browse all X4 wares with base buy and sell price ranges |
